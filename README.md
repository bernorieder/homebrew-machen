# homebrew-machen

The Homebrew tap for [machen](https://machen.polsys.net), a Mac menu bar app for Google Calendar events and Google Tasks.

```sh
brew install bernorieder/machen/machen
```

The cask downloads the signed and notarized DMG of the latest release. To update, run `brew upgrade machen`, then open machen again: Homebrew quits it to replace it.
